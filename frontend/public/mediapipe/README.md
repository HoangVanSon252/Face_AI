# MediaPipe assets

- `blaze_face_short_range.tflite` — MediaPipe BlazeFace short-range face detector
  (float16, v1), Apache-2.0, from
  https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/1/blaze_face_short_range.tflite
  SHA-256 `b4578f35940bf5a1a655214a1cce5cab13eba73c1297cd78e1a04c2380b0152f`.
- `wasm/` — generated by `scripts/copy-mediapipe-wasm.mjs` from `@mediapipe/tasks-vision`
  (not committed).

Used only in the browser to decide *when* a webcam frame is worth sending to the
server (one face, large enough, centred). Recognition and anti-spoofing stay on
the server.
